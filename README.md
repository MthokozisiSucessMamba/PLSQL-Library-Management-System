# PLSQL Library Management System

## Description

This project is a Library Management System developed using Oracle PL/SQL.

The system manages books, library members, and book loans. It demonstrates different PL/SQL concepts such as tables, procedures, functions, cursors, and packages.

## Features

- Manage library books
- Manage library members
- Borrow books
- Return books
- Calculate fines
- Check available books
- Count member loans
- Display borrowed books
- Display overdue books

## PL/SQL Concepts Used

- Tables
- Primary Keys
- Foreign Keys
- INSERT statements
- Stored Procedures
- Functions
- Cursors
- Packages
- Exception Handling
- SQL Queries
